The wiki's fact box. Labels left in small caps, values right-aligned.

```jsx
<InfoBox title="The Drowned Coast" rows={[
  { label: "Region", value: "West littoral" },
  { label: "Seat", value: "Marrow Bay" },
  { label: "Houses", value: "Marrow, Calder" }
]} />
```

Six to eight rows maximum — it is a summary, not the article. Values stay short enough not to wrap
twice.
