Wraps every image on the site. Never place a bare <img> on a Starfall page.

```jsx
<ImageFrame ratio="4 / 3" float scrim="card">
  <img src="assets/atlas.jpg" alt="" style={{ width: "100%", height: "100%", objectFit: "cover" }} />
</ImageFrame>
```

Art guidance: dark overall value, one light source, atmospheric haze, quiet centre. Cool blues and
violets so gold type separates. Minimum 2560px wide for anything full-bleed.
