Letterspaced small-caps chip for tag rows (races, feature lists) and hero eyebrows.

```jsx
<Pill href="#wiki">Tidemarked</Pill>
<Pill tone="outline">A Pyrelight Press world · 5e compatible</Pill>
```

Use `outline` when the pill sits over key art (it carries its own scrim). `gold` is reserved for
the "Premium" product badge — do not use it for navigation.
